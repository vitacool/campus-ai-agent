# 30 秒演示脚本

## 演示目标

让招聘方快速看到：这个项目不是静态 Demo，而是一个具备问答、检索解释、后台维护和反馈闭环的 AI 应用。

## 操作流程

1. 打开首页：`http://127.0.0.1:8000`
2. 点击“部门电话”快捷问题。
3. 展示回答中的来源、得分、命中词、检索模式和工具路由。
4. 点击“有帮助”，展示反馈已记录。
5. 打开后台：`http://127.0.0.1:8000/admin`
6. 新增一个知识条目，例如：
   - ID：`canteen-hours`
   - 标题：`食堂开放时间`
   - 分类：`校园服务`
   - 内容：`第一食堂每天7:00-21:00开放。`
   - 关键词：`食堂,开放,时间`
7. 回到首页提问：`食堂几点开放？`
8. 展示新知识被召回，说明后台保存后会自动重建向量索引。

## 讲解词

这个项目面向校园高频服务问答场景。我做了 FastAPI 后端、混合向量检索、Agent 工具路由和后台知识库管理。用户提问后，系统会先判断问题意图，再用向量检索和关键词 fallback 召回知识库，最后返回答案、来源、得分和检索模式。后台可以维护知识条目，保存后会自动重建索引，所以它不是一次性的问答 Demo，而是一个可维护的 AI 应用原型。
